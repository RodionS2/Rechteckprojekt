# Rechteckprojekt - Windows Forms

Projektarbeit für die Schule.

## Beschreibung
Mein Programm berechnet die Fläche, den Umfang und die Diagonale von einem Rechteck oder Quadrat. Man kann das Rechteck auch um 90 Grad drehen und mit einem Faktor zoomen.

## Funktionen
- Klasse Rechteck (mit Validierung: Zahlen müssen > 0 sein).
- Zwei Konstruktoren (für normales Rechteck und für Quadrat).
- GUI mit Try-Catch (damit das Programm bei Fehlern nicht abstürzt).
